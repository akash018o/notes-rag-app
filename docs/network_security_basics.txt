Network Security Basics

A firewall is a system that filters network traffic based on rules. It sits between a trusted network, such as a company LAN, and an untrusted one, such as the internet, and allows or blocks traffic depending on things like IP address, port, and protocol. Modern next-generation firewalls can also inspect the content of traffic and identify applications. An intrusion detection system, or IDS, monitors traffic and raises alerts about suspicious activity. An intrusion prevention system, or IPS, goes further and can automatically block the traffic.

A VPN, or virtual private network, creates an encrypted tunnel between your device and another network. It protects data from being read on untrusted networks such as public Wi-Fi and lets remote workers reach internal company resources. A VPN does not make you anonymous and does not protect against malware.

Encryption protects data in two main states. Data in transit, such as web traffic, is protected with TLS, the protocol behind HTTPS. Data at rest, such as files on a disk, is protected with disk or file encryption. Symmetric encryption uses one shared key and is fast. Asymmetric encryption uses a public and private key pair and is used to exchange keys and create digital signatures.

Common network attacks include the following. A denial-of-service attack floods a service with traffic so legitimate users cannot reach it; when it comes from many machines at once it is called a distributed denial-of-service, or DDoS, attack. A man-in-the-middle attack secretly intercepts and possibly alters communication between two parties. A port scan probes a machine to find which services are listening. SQL injection is a web application attack in which the attacker inserts database commands into an input field to read or change data; it is prevented by using parameterized queries. Cross-site scripting, or XSS, injects malicious scripts into web pages viewed by other users.

Key principles for defence include least privilege, giving users and programs only the access they need; defence in depth, using multiple layers of protection so one failure is not fatal; network segmentation, splitting a network into zones to limit how far an attacker can move; and regular patching, because many attacks exploit known vulnerabilities in outdated software. Regular backups, kept offline or otherwise separate from the main network, are the main protection against ransomware.
